What this is

and what the labels mean

This site is an index. It holds no code or data of its own; every link goes to a repository on GitHub or to a live site built from one.

It started in 2025 as the home page for eight related "stacks". Five of them are in use and are listed under research toolkits. The other three (RootStack, BridgeStack and ViewStack) were a database, an API and a dashboard that the toolkits did not need; they are archived and listed at the bottom of the page.

Every repository has one of the four labels on the right. The maintenance policy says what each label commits the maintainer to. Code is MIT-licensed unless a repository says otherwise; some written material is under Creative Commons. Each repository stands on its own, with its own README and no shared dependency.

Active

Being worked on. Issues and pull requests get a reply within days.

Stable

Works as described and is not being developed. Bug reports are welcome and may wait weeks for a reply. New features are unlikely.

Prototype

Unfinished, and shared as it is. Lives in the Experiments repository until it gets a repository of its own or is dropped.

Retired

Archived on GitHub and read-only. Kept public so that links, citations and forks continue to work.

Hyderabad Electoral Analysis

Five old-city seats, one winner since 1999, and still the poorest part of Hyderabad. Ward-level census data shows the gap is in work and income rather than services or slums: water and drainage are at full parity, but a third fewer people have jobs. The only gaps that closed since 2011 were closed by national schemes. Includes a run of the standard causal test, which cannot answer either way from public data.

varnasr.github.io/Hyderabad-Electoral-Analysiselectionscensusdata stable

RootStack

SQLite and PostgreSQL schemas for the shared data layer.

BridgeStack

FastAPI backend serving RootStack to frontends.

ViewStack

React dashboard for exploring the data.

These three were a database, an API and a dashboard, built as one pipeline. It cost the most to maintain, was used the least, and the research toolkits never depended on it.

ImpactLex is not on this list. Its old repository is archived, but the project graduated into Impact Mojo rather than winding down; it is listed under Teaching and practice above. An archived repository and a finished project are not the same thing.

Four further stacks (ClimateStack, EduStack, SocialStack and InfraStack) sat on a published roadmap for a year without a line of code written. That roadmap has been withdrawn rather than left standing as a promise to readers. The needs behind it are better served by How India Lives, PolicyDhara and JanVayu.

People working on health, education, gender, climate and governance, mostly in India and South Asia.
